# Support

Use the channel that matches the kind of help you need. Do not include
credentials, personal data, customer data, or production URLs in public posts.

## Using the Platform

Start with the [Quickstart](https://aiforce-consulting.github.io/agentic-web-intelligence/quickstart/), the
[documentation site](https://aiforce-consulting.github.io/agentic-web-intelligence/),
and the [Local Evidence Intelligence guide](https://aiforce-consulting.github.io/agentic-web-intelligence/local-evidence-intelligence/).

For usage questions, design discussion, or ideas that are still forming, use
[GitHub Discussions](https://github.com/AIFORCE-CONSULTING/agentic-web-intelligence/discussions).

## Bugs and Documentation Problems

Use the bug-report issue form for a reproducible defect. Include the platform
version or commit, clear reproduction steps, expected and actual behavior, and
sanitized logs or screenshots when helpful.

Use a pull request or an issue for documentation corrections. Small factual
corrections are welcome; see the [contribution guide](https://github.com/AIFORCE-CONSULTING/agentic-web-intelligence/blob/main/CONTRIBUTING.md) for the broader
contribution process.

## Features and Architecture Ideas

Use the capability-proposal issue form for a proposed platform improvement.
Describe the intended outcome, affected users, constraints, security or privacy
considerations, and acceptance criteria. For a non-trivial change, wait for a
maintainer response before beginning implementation.

## Security Vulnerabilities

Do not create a public issue, discussion, or pull request for a suspected
vulnerability, leaked credential, or weakness that could expose a system or
data. Use GitHub's private vulnerability reporting for this repository as
described in the [security policy](https://github.com/AIFORCE-CONSULTING/agentic-web-intelligence/blob/main/SECURITY.md).

The project does not currently provide a paid support plan or response-time
guarantee.
